# Hospital-Management
This project by made by Parth Verma in 2024 as Class XII end project. It uses Pyton as frontend or user interaction and SQL as backend for storing, fetching, et cetra of data. In this project, the user can store, modify, delete or fetch data of a patient, including all of the tests conducted, room charge, date of admission, et cetra. Same goes for the manipulation of the data of doctors. It also has an option for OPD, for each date, its type and option for various doctors. The user can also prepare the bill based on room rent, tests charges, duration, et cetra. The salary of doctors can also be manipulated.
